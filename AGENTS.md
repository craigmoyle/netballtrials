## Agent skills

### Issue tracker

Issues and specs are tracked in GitHub Issues for `craigmoyle/netballtrials`; use `gh`. PRs are not a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the default labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Use the multi-context layout described in `GLOSSARY-MAP.md`, and read the ADRs relevant to the affected workspace. See `docs/agents/domain.md`.
